# LexiLab

Небольшой тренажёр английских слов: карточки, интервальное повторение по системе Лейтнера и личная статистика. Проект соединяет интерес к языкам с алгоритмическим подходом к обучению.

## Возможности

- Шесть стартовых карточек и добавление собственных слов с примерами.
- Повторение по уровням: после верного ответа карточка появляется через 1, 3, 7, 14 или 30 дней; после ошибки — через минуту.
- Счётчик повторений, очередь на сегодня и серия дней занятий.
- Хранение данных в `localStorage` браузера. Данные не передаются на сервер; при очистке хранилища они исчезнут.
- Управление с клавиатуры: `Пробел` показывает перевод, `1` означает «повторить», `2` — «помню».

## Запуск

Нужен любой локальный статический сервер, потому что приложение использует JavaScript-модули. Например:

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>. Для проверки логики выполните `npm test` (Node.js 20+; дополнительных пакетов нет).

## Технологии и идея

HTML, CSS, JavaScript без фреймворка. Логика повторения вынесена в `logic.js`, интерфейс — в `app.js`. Алгоритм Лейтнера хранит уровень каждой карточки и назначает дату следующего показа. В проекте есть тесты расписания и обработки слов.

Это учебный проект о языках и алгоритмах, а не готовая система компьютерной лингвистики. Следующим шагом можно добавить поиск по формам слов и импорт словаря.

## Публикация на GitHub Pages

Создайте публичный репозиторий `lexilab`, загрузите файлы из этой папки в его корень. В настройках репозитория откройте **Pages → Build and deployment**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. После публикации добавьте ссылки на репозиторий и страницу в резюме.
