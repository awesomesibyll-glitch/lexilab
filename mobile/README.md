# LexiLab для телефона

Устанавливаемое веб-приложение для iPhone и Android: карточки английских слов, интервальное повторение, поиск, свои слова и работа без сети после первого открытия. Это PWA, а не файл IPA/APK и не приложение в App Store или Google Play.

## Словарь

Встроена небольшая проверенная стартовая подборка. Чтобы подключить большой словарь, скачайте англо-русский TEI-файл FreeDict через ссылку во вкладке «Словарь», а затем выберите скачанный файл в приложении. Источник насчитывает около 62 тысяч словарных статей; число реально импортированных пар показывается после импорта. Повторение остаётся управляемым: добавляйте в изучение только нужные вам слова.

FreeDict English–Russian, release 2025.11.23: https://freedict.org/downloads/ . Исходный файл: https://download.freedict.org/generated/eng-rus/eng-rus.tei . Данные словаря распространяются по лицензии CC BY-SA 3.0; сведения о лицензии: https://download.freedict.org/generated/eng-rus/COPYING . Приложение извлекает английское заглавное слово и до трёх русских переводов. Данные из файла сохраняются в IndexedDB только на устройстве пользователя; код приложения не включает сам большой словарь.

## Как запустить и установить

Файлы должны лежать в корне сайта с HTTPS (например, GitHub Pages). Для локальной проверки из этой папки выполните `python3 -m http.server 8000`, затем откройте `http://localhost:8000`.

- **iPhone:** откройте сайт в Safari, нажмите «Поделиться» → «На экран Домой» → «Добавить».
- **Android:** откройте сайт в Chrome, нажмите «Установить» или меню ⋮ → «Добавить на главный экран».

После первого открытия интерфейс и встроенные слова кэшируются для работы без сети. Для первоначального скачивания TEI-файла интернет нужен. Прогресс хранится в браузере; очистка данных сайта удалит его. Данные прежней версии LexiLab по возможности переносятся из `localStorage` того же сайта.

## Публикация

Файлы этой версии расположены в папке `mobile/` репозитория `lexilab`. GitHub Pages публикует их по адресу `https://awesomesibyll-glitch.github.io/lexilab/mobile/`. Основная версия LexiLab в корне репозитория остаётся доступной отдельно.

Для проверки логики: `npm test` (Node.js 20+). Дополнительных зависимостей нет.
